What this is

skillsmith-web is a free, open-source (MIT-licensed) demo of the skillsmith CLI/library: a static lint and heuristic security scanner for Claude Agent Skill (SKILL.md) files.

No warranty

This is a static, heuristic, no-sandbox scanner. It is a triage aid, not a substitute for actually reading code before running it, and it is provided "as is" without warranty of any kind. A "clean" result does not guarantee a skill is safe; a flagged result does not guarantee a skill is malicious. See the GitHub repo for exactly what is and isn't checked.

Acceptable use

Don't use this service to try to break, overload, or scrape it at abusive volume, and don't submit content you don't have the right to share. The free tier and the paid Pro tier both have reasonable rate/size limits (see the README) to keep the service usable for everyone.

Pro tier payments

The Pro batch API is pay-per-call via an on-chain USDC (Solana) transfer, verified against the public Solana ledger. Payments are for API usage at the time of the call; there are no subscriptions, no refunds process beyond good-faith review of on-chain evidence, and no guarantee of availability beyond commercially reasonable effort to keep the service running.

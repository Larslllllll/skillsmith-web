Pro: batch-scan up to 25 skills, $0.02 USDC per call

For CI pipelines and repos with many skills. Pay in USDC on Solana, no account, no subscription. POST /api/scan-pro with no payment_signature returns the pay-to address and price; pay, then resubmit with the transaction signature to run the batch. Testable for free with a test_signature_* value. See docs on GitHub. 

curl -X POST https://skillsmith-web.vercel.app/api/scan-pro \
  -H "Content-Type: application/json" \
  -d '{"files":[{"name":"a/SKILL.md","text":"..."},{"name":"b/SKILL.md","text":"..."}]}'
→ 402 Payment Required: {"price_usdc": 0.02, "pay_to": "2esJogvKTYDuxZaB9PEuEaHvz4U6TuQnTx3pkLcdH34N", "mint": "USDC"}
